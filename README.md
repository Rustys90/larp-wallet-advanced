# Advanced Larp Wallet Simulator

Multi-skin wallet for screenshots, videos & content.

## Skins
| File | App |
|------|-----|
| `index.html` | **Phantom** |
| `trust.html` | **Trust Wallet** |
| `paypal.html` | **PayPal** |
| `hub.html` | Skin picker |

## Features
- Editable balances (LocalStorage, shared)
- Working money flows (send / receive / swap / buy)
- Activity history editor
- Skeleton loaders
- Live prices (Phantom/Trust via CoinGecko)
- Skin switcher in Settings

## Run
Open any HTML file in mobile Chrome / device mode, or serve the folder statically.

Live: https://larp-wallet-advanced.netlify.app/
